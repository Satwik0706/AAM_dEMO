# String Matching Workbench (Vercel Ready)

Interactive full-stack web visualizer for **Naive**, **Rabin-Karp**, **Finite Automata**, and **Knuth-Morris-Pratt (KMP)** string matching algorithms.

## Deploy to Vercel (via Git)
1. Push the `string_matching_visualizer` folder to a GitHub repository.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Leave Framework Preset as **Other** (configured automatically by `vercel.json`) and click **Deploy**.

## Run Locally
```bash
pip install -r requirements.txt
python backend/app.py
```
Then open `http://localhost:5000`.
